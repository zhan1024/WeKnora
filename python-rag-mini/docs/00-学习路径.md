# WeKnora → Python/LangChain 对照学习路径

本项目(`python-rag-mini/`)是腾讯 WeKnora(Go)RAG 核心链路的 Python 精简复刻,
目标是让你**用几百行 Python 看懂几万行 Go 在做什么**。

## 推荐阅读顺序

| 顺序 | 主题 | 精简版代码 | WeKnora 对应代码 | 文档 |
|---|---|---|---|---|
| 1 | 混合检索与 RRF 融合(已在上一步完成) | `rag/hybrid.py` | `internal/application/service/knowledgebase_search_fusion.go` | 见 README 对照表 |
| 2 | 文档解析管线 | `rag/parsers.py` `rag/chunker.py` `rag/pipeline.py` | `docreader/` `internal/infrastructure/chunker/` `knowledge_process.go` | [01-文档解析管线对照](01-文档解析管线对照.md) |
| 3 | 流式协议与引用解码 | `rag/stream.py` `rag/qa.py:stream_answer` | `internal/stream/` `internal/modelcontext/citations.go` | [02-流协议对照](02-流协议对照.md) |

## 快速验证

```bash
cd python-rag-mini
source .venv/bin/activate

# 文档解析管线:支持 md/txt/html/docx/pdf
python main.py ingest sample_data

# 一次性问答
python main.py ask "WeKnora 支持哪些向量数据库?"

# 流式问答(观察 SSE 事件帧与 <ref> 标签的跨边界重组)
python main.py ask "RRF 融合是怎么工作的?" --stream
```

## 学习方法建议

1. **先跑再看**:每条链路先用 CLI 跑一遍,看到输出再读代码
2. **对照读**:精简版每个函数 docstring 都标了 Go 侧文件位置,两边同时打开
3. **改参数看变化**:比如把 `rag/hybrid.py` 的 `DEFAULT_VECTOR_WEIGHT` 改成 0.3,
   再跑同一个问题,观察排序变化 —— 比读十遍文档理解得快
4. **断点验证**:精简版每个模块都有断言级测试过,你也可以拆开单独 import 做实验
