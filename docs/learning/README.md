# WeKnora 从零到一学习与面试手册

> 适用仓库：当前 `Tencent/WeKnora` 源码与本仓库内的 `python-rag-mini/`。
> 目标不是“看完资料”，而是做到：**能运行、能改代码、能画数据流、能经得住面试追问**。

## 1. 两个项目分别学什么

| 项目 | 适合学习 | 不适合假装已经掌握 |
|---|---|---|
| WeKnora 主项目 | 企业级多租户、异步文档管线、多向量引擎、RAG 插件管线、Agent、MCP、长期记忆 | 在没有实际部署和压测前，不声称自己完成了生产级改造 |
| `python-rag-mini` | 用少量 Python 代码理解解析、分块、混合检索、RRF、引用、SSE 和前端联调 | mini 目前没有实现完整 RBAC、Agent ReAct、MCP、持久化向量库和长期记忆 |

**重要边界**：mini 是对照学习实现，不是 WeKnora 的功能完整替代。阅读每篇文档时，注意区分“主项目已有能力”和“mini 已复刻能力”。

## 3. 每个学习单元的统一方法

按下面顺序，不要只收藏文档：

1. **跑**：执行文档里的最小命令，保留输出。
2. **画**：画出该模块输入、处理、输出、失败路径。
3. **读**：从文档链接跳到源码，找到同名函数。
4. **改**：只改一个参数或一个小函数，观察行为差异。
5. **证**：用测试、curl、日志或截图证明改动生效。
6. **讲**：用“结论 → 机制 → 实现 → 边界 → 项目例子”讲两分钟。

### WeKnora 主项目

完整部署通常使用 Docker Compose；本地前端开发代理可按本机已有配置连接远程服务。启动前先看 [架构与从零启动](01-architecture-and-setup.md)，不要把前端开发服务器误当成后端。

source .venv/bin/activate
